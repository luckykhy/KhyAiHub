aiGatewayGenerateMethod#

网关统一生成入口的实现体。aiGateway.js 把「一次生成」的全部策略收在这里：通道选择与降级、
空闲看门狗与 idle-progress 判定（gatewayIdleProgressPolicy）、图片/视觉通道路径、
重试预算（与 constants/retryBudget.js 同批约束）、以及 MCP 工具调用取用的绑定。
