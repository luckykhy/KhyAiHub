ccSwitch — 供应商卡片切换与本地代理路由#

D2 业务上下文里的一个功能单元：CC-Switch 式的「供应商卡片」注册表 + 活跃卡片到本地代理的路由 +
写入器（Codex / 应用配置）+ 连通性规格 + 用量与计价扫描。11 个源文件全部有同名同目录的共置测试
（206 例 / 0 fail，2026-09-29 本道显式路径复跑；grep -c KNOWN-DEFECT 实测 56 处钉住）。

各文件的职责（取自各文件头注释）#

文件角色
store.jsCC-Switch 风格的 provider-card 注册表（落盘真源）
routeResolver.js活跃卡片 → 本地代理的路由
promptGuard.js恢复时保护非受管的 prompt 文件（CC Switch #6810 语义）
apiHandlers.js / connectivity.jsHTTP 面处理与连通性规格消费
appWriters.js / codexWriter.js / proxyAccess.js应用侧配置写入与代理接入
constants.js / opencodeGoQuota.js / usageScan.js协议/别名常量、OpenCode Go 配额、用量与计价扫描

谁在用本单元（非测试外部消费者 4 个）#

cli/handlers/ccSwitch.js（CLI/TUI 主交互面）、routes/ccSwitch.js（HTTP 面）、
services/ccSwitch/index.js（D1 历史路径再导出壳）、services/crossAgentTasteLearner.js。
