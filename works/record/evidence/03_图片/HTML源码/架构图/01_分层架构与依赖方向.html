层级 L0–L6（顶层七板块）
L0
kernel/
手写 OS 内核：调度 / 分页 / COW fork / 中断 / ELF+PE 双加载器
L1
platform/
Python 启动器（探测环境、拉起 Node）+ 共享包 + 交付编排
L2
services/
Node 运行时，全部业务逻辑：CLI、AI 网关、Web API
L3
apps/
平台自带管理前端（AI 平台 UI）
L4
software/
跑在平台之上的独立项目载体（khyquant 量化终端：独立项目，连接平台使用）
L5
extensions/
内置拓展，随主包分发，运行时被发现并激活
L6
tools/
独立开发者工具，不参与运行时
横切层（不参与 L0–L6 依赖判定）
scripts/ · packaging/ · docs/ · _source/ · entries/ · evidence/ · electron/ · tests/ · deploy/ · patches/
允许的依赖方向（白名单）
✅ L1 → L2：进程启动（spawn），非模块导入
✅ L2 → L1：workspace 包导入 @khy/shared
✅ L3 → L2：HTTP / REST，不得跨目录 import
✅ L4 → L2：HTTP + 少量进程调用
✅ L4 → L1：打包清单
✅ L2 → L4：仅限纯 re-export 壳
✅ 横切 → 任意层：按路径引用
禁止边（守卫 cross-layer-require 执行）
⛔ L0 与任何层之间：内核独立，与 Node 栈无运行时耦合
⛔ L3 ↔ L4：两个前端不得互相 import
⛔ L2 → L3：后端不得反向 import 前端源码
⛔ 任何层 → L5 / L6：拓展与工具是叶子，只按契约被发现
⛔ 跨 workspace 的深层相对路径 require
