1.3 边的机制枚举（mechanism）#

机制含义
require静态 require() 依赖（模块加载期建立）

function-call函数/方法调用（含惰性 require 后调用、依赖注入 setter 注入）
inline-literal数据以对象/数组/字符串字面量形式内联在代码文件中，无独立资产文件

homedir-pathos.homedir() / 用户家目录字面量拼路径
process-spawnchild_process 派生子进程
sql-query裸 SQL / DDL 字符串
