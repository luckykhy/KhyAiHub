  • For the khy-mobile app, treats "可单独调用" (each feature independently callable) as a hard product-design invariant, not just code cleanliness. Wants verification surfaces (e.g. model chip in /chat) to be reachable from any page as inline buttons, not only from a configuration page — so the user never has to navigate somewhere else to verify current state.
