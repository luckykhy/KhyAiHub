# [LAYOUT-008] 数据事实单一真源与影子副本归并

> 正文原文在 `ssot` 指向的位置：docs/10_规范/DESIGN-LAY/[DESIGN-LAY-009] 数据单一真源与影子副本归并规范.md。

## 约束

同一事实只允许有一个真源，其余位置必须从真源取值；物理上无法 import 的跨包镜像必须登记在 DATA-SSOT.json 的 mirrors 里并写明理由，且必须与真源锁步；真源文件、真值指针、镜像登记任一失效时报红；登记表中不得另存一份值。

## 授予权力

授权在 S1 阶段据候选清单人工判断是否归并；授权把跨包镜像登记为授权镜像而不强行跨包重构；授权对同名不同义的事实用 detect.paths 划定作用域而不改代码。

## 提供福利

把「单一真源」从纪律变成可判定的不变式：实测首轮命中 10 处同包影子副本（全在 runtime/node/backend 内，能 import 却各自写死）与 1 处真源自相矛盾（规则登记表 meta.ruleCount 声明 96 而实有 99），归并后影子副本归零；6 个跨包授权镜像全部锁步，仓内无登记表的逐字节副本。

## 反例

见 `ssot` 指向的真源原文；本卡不复制反例，以免与真源漂移。

## 校验方式

人工评审（该规则暂无机械守卫）

## 例外

测试目录与测试文件不判（测试固定规范值是防护，不是第二真源）；文档里的数值主张由 DOCS-006/DOCS-007 负责；无标识符锚点的字面量兜底判不出；同名不同义的事实（如协作桥端口与手机桥端口）以 detect.paths 划界而非全局判定；S1 阶段只记录不阻断。
