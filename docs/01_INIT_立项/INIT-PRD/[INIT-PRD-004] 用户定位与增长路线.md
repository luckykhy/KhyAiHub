# [INIT-PRD-004] 用户定位与增长路线 —— 主攻用户、价值主张与三阶段路线

> **定位**：回答三个此前全仓无真源的问题——**khy-os 的用户是谁、用户凭什么需要它、接下来按什么顺序做**。
> **性质**：定位层文档，与 [`INIT-PRD-002`](INIT-PRD-002%20项目-定位.md)（对外叙事）、[`INIT-PRD-003`](INIT-PRD-003%20KhyOS%20的核心-定位口径单一真源.md)（核心口径收口）互补：002 讲「我们是什么」，003 讲「核心是哪几块」，**本文讲「为谁做、凭什么、先做什么」**。
> **证据基线**：2026-09-23。PyPI/npm 下载数为当日实拉（复现命令见附录）；路线图任务面以 `.ai/hq/PROGRESS.json` 24 条任务当日读数为准。
> **状态**：定稿（2026-09-23）。本文不新增规范、不新增守卫；排期裁决真源仍是 `PROCESS-102`，本文的三阶段是它在**用户价值维度的排序输入**。

## 〇、一句话

**khy-os 的滩头用户是「中文 AI 重度用户——手里攥着 2~5 家 AI 订阅、成本敏感、想要一个终端吃遍所有 AI 的超级个体」；获客主张不是「又一个 Claude Code」，而是 Claude Code 结构上给不了的四件事：订阅套利（省钱）、随身性（微信/手机）、本土化、数据私有。**

增长路线三阶段：**A 收窄（订阅套利终端做实）→ B 放大（随身性）→ C 纵深（垂直场景验证「平台」心智）**。维护类任务产能封顶 30%（见 §四）。

## 二、用户群体：四层，只主攻一层

| 层 | 画像 | 凭什么用 | 裁决 |
| --- | --- | --- | --- |
| **S1 中文多订阅重度用户** | 手里 2~5 家 AI 订阅（Claude/Codex/Cursor/Kiro/Trae/国内模型），月花 ¥200~800，Windows 便携党，成本敏感 | 一个 CLI 吃遍所有订阅 + 自动故障转移 + 人民币计价省钱报告 | **主攻，滩头阵地（本文全部分析围绕它）** |
| S2 量化爱好者 | 想用 AI 辅助做策略研究/回测的散户 | khyquant 内置应用 | 第二阶段纵深，不当第一卖点（003 已裁决 khyquant=示例应用） |
| S3 想要「随身 AI」的个人 | 希望在微信/手机上随时使唤自己的 agent | 微信 ilink + 手机 APK + 四端同步 | 第二阶段放大（独有 wow 点） |
| S4 私有部署者 | 内网/隐私敏感、想自托管 AI 工作台 | 便携版、数据全本地、source-available | 顺带承接，不专门投入 |

**明确不是用户**：被「手写 C 内核」吸引来的人。内核是招牌与练兵场（003 §4.1 已裁决其为实验分支），保持叙事资产地位、零工程投入。

**S1 为什么是滩头**：AI 重度用户的剩余瓶颈不再是「AI 会不会写」，而是**订阅太贵、额度分散、网络不稳、换机环境重配、离开电脑就使唤不了 agent**。这些恰是 khy-os 已有资产的射程，也恰是 Claude Code 的结构盲区（它永远不会帮你接 Cursor 的订阅）。

**基线数字（2026-09-23 实拉，作为一切增长验证的对照组）**：

| 渠道 | 指标 | 数值 |
| --- | --- | --- |
| PyPI（pypistats.org） | 近一日 / 近一周 / 近一月下载 | 5 / 92 / 173 |
| npm（api.npmjs.org） | 近一周 / 近一月下载 | 12 / 61 |

> 口径说明：PyPI 含镜像去重前口径（pypistats `without_mirrors` 与 total 差异大），npm 为 point 口径。基线的意义不在绝对值大小，在于**此后任何增长动作都必须能用这组数字验证**。

## 三、「凭什么需要」：四条真实理由 + 一条反例

对照基线定为「用户直接用 Claude Code」，逐条过：

1. **省钱是硬通货**。网关熔断/故障转移 + 19 个 `*Adapter.js`（含大量订阅态 relay 型适配器），等于「订阅额度自动套利」；`tokenUsageService` 已按人民币计价，只差最后一公里：**「直连官方价 vs 实际花费 = 省了 ¥X」的月度报告**。这是唯一能用**钱**而非体验证明的差异点。
2. **随身性是独有 wow**。微信里发一句话、agent 干完活回来汇报——当前主流工具没有这个入口。T-001 完成即天然传播素材。
3. **本土化**：中文/拼音别名（`aliases.js`）、中文错误消息（AGENTS.md 规则 2.2 错误模板）、国内模型优先、国内镜像。
4. **私有与便携**：数据全本地、便携版、`khy doctor`、source-available。对 S4 是必要条件，对 S1 是加分项。

**反例（不作为获客卖点）**：「平台/操作系统」心智。它是**留存**故事（用顺了离不开），不是**获客**故事（新用户不会为「可装 App 的基座」付费）。「OS」一词留给内核与愿景；获客话术必须落在上述四条。

**一句话定位（README 首屏候选）**：

> **khy-os：给中文 AI 重度用户的一台「AI 主机」——一个终端吃遍你所有 AI 订阅，自动省钱、自动容错；微信和手机上，随时使唤它。**

## 四、40 倍效率论：从口号变成三把尺子

40x 的正确用法不是宣传语，是**排期过滤器**。三个机制：

1. **任务登记加一维 `user-delta`**：PROCESS-102 已有 cod/conf/size 三字段（hqStore 已实现校验），再加一个「这活让哪类用户的什么动作，从 X 分钟/¥Y 变成多少」。填不出来（只能说「代码更整洁」）的任务自动归维护预算线，**封顶 30% 产能**。
2. **40x 自我记账**：作者本人是 S1 的 0 号用户。把「本月 khy 替我省了多少时间/钱」按月记入 CHANGELOG 或月报——40x 不是宣称出来的，是**记出来的**，且是现成营销素材。
3. **一票否决判定**：任何功能若唯一立项理由是「别人有所以我们也要有」，40x 检验不过——砍。现有反例：横向继续加第 20 个 adapter（除非种子用户的订阅真的需要）。

> 落地注：`user-delta` 字段的登记位置与机器校验属独立一轮工作（改 `hqStore.validateTask` + `PROGRESS.json` schema + 提示词模板），本文只登记语义，不擅自改命令面。

## 五、三阶段路线（出口条件制，不达标不进下一阶段）

### 阶段 A（0→1，约 4~6 周）：把「订阅套利终端」做实

| # | 动作 | 对应资产/任务 |
| --- | --- | --- |
| A1 | `khy onboard` 一键纳管：探测本机已有 Claude/Codex/Cursor/Kiro/Trae 登录态与 key，一键接入网关 | **T-023 KeyManager（done，2026-09-23 过验收清算门）就是这条的钥匙**；`codexCredentialProbe.js`/`ccEnvAdoptPolicy.js`/`ideDetector.js` 已是地基 |
| A2 | 月度省钱报告：直连官方价 vs 实际花费，人民币结算 | tokenUsageService 人民币计价已有 |
| A3 | 首跑 10 分钟承诺：`pip install khy-os && khy` 后 10 分钟内跑通第一次对话；README 首屏从架构语言改写成用户语言 | `khy preflight`/`khy doctor` 已有；定位话术见 §三 |
| A4 | 种子用户 10~30 人（V2EX/知乎/即刻/linux.do/微信群），只问一个问题：「你为什么留下/卸载？」 | 答案按 RUNTIME-008 五问格式落档，**必须带 `source: 用户原话`** |

**出口条件**：① ≥10 个非本人用户周留存，且留存理由落在「省钱/中文/便携」三关键词内；② 增长以 §二基线数字为对照。

### 阶段 B（1→10，约 2~3 个月）：放大「随身性」

- **B1** 收尾 T-001 微信 ilink 闭环 → 拍「在微信里使唤 khy」演示视频（全项目最便宜的获客素材）。
- **B2** T-022 四端同步**砍成最小闭环**：先只做「手机 APK ↔ 桌面端同一会话续聊」，不一上来铺四端。APK 骨架 T-013 保留，T-014/15 顺延。
- **B3** 网关实盘透明化：`khy gateway status` 显示各家近 7 天成功率/延迟/切换次数——故障转移从「有」变成「用户看得见、敢托付」。
- **B4** 插件故事最小化：现有 `extensions/` 约定（删目录即卸载）包装成「3 行写一个 khy 插件」教程，**不做插件市场**。

**出口条件**：微信通道被种子用户日常使用；手机续聊跑通；「哪家稳/哪家省」数据可截屏传播。

### 阶段 C（10→100，3~6 个月）：垂直纵深，验证「平台」心智

- **C1** khyquant 作为「基座+内置应用」模式的样板间：若 S1 用户里长不出 10 个量化日活，「AI OS 能装 App」叙事即证伪——**这是整个 OS 心智的试金石**。
- **C2** 运行时管理 T-008/009（网页端装 node/jdk 环境）排入此阶段，强化「这台机器管一切」心智。
- **C3** 内核线转纯品牌内容（视频/文章），不占工程产能。

### 恒定线（产能封顶 30%）与停做清单

- **恒定线**：质量债（T-016~021 重构按既有计划）、版本/发布纪律。地基不必天天浇。
- **建议停做/降级**：T-006（多机 N 机协作扩张——作者的问题不是用户的问题，降 P3）；T-019（死功能盘点，P3 保持）；横向新增 adapter（冻结，除非种子用户点名）。

## 八、定位的代码化（2026-09-23，T-029 done）

定位不是文档专属品——**话术真源已落入代码，产品面全部同源渲染**：

| 落点 | 作用 |
| --- | --- |
| `services/backend/src/constants/positioning.js` | **定位话术单一真源**（tagline/一句话/四主张/人群/OS 释义/doc 指针），纯叶子零 IO |
| `services/backend/src/cli/handlers/about.js` | **`khy about`**（别名 `关于`/`guanyu`，自注册命令）：一屏回答「为谁做/凭什么/OS 何来」 |
| `bannerDataService.js` / `formatters.js` / `repl/startupHeader.js` | 经典横幅三条路径（共享数据服务/全横幅/盒式首屏）第二行渲染 tagline |
| `tui/ink-components/WelcomeBanner.js` | TUI 横幅版本行下渲染 tagline（`ROWS_BEFORE_VERSION=0` 契约不受影响） |
| `cli/tui/utils/ccBrand.js` | `tagline`/`welcomeSubtitle` 改取自定位真源——品牌串不再有两份口径，BootScreen/CcLogo 链式跟随 |
| `services/backend/tests/positioning.test.js` | 锁定不变式：形状完整/四主张恒在/品牌链同源（`logoArt.TAGLINE === BRAND.tagline === POSITIONING.tagline`）/渲染面可见/manifest 合法 |

**「OS」之名的代码映射**（`khy about` 直接对外讲的四层栈）：

- `kernel` — 手写 C 内核（实验分支，QEMU 可引导，`khy os`）；
- `runtime` — 壳 → 漏斗 → 网关（不可卸载核，模型调用即系统调用，[INIT-PRD-003] 口径）；
- `apps` — ai-frontend / 桌面端 / 手机端 / khyquant（可增删）；
- `extensions` — 一个目录一个拓展，删目录即卸载。

即：**khy-os 的 OS = 统一收口的运行时（内核类比）+ 可增删的应用/拓展单元（生态类比）**，这两点在代码结构里本就成立，`khy about` 只是把它们说给用户听。
