[RESEARCH-018] 5-3-1 架构理论框架符合性调研与迁移设计#

一次性调研快照（写完即冻结）。触发：用户 2026-09-28 下达「以 5-3-1 架构理论框架（米勒定律 7±2 / 三维定位 / 5-3-1 结构模型 / 动态流转 / 零破坏约束）为硬约束，自主考古本仓并推导新架构 + 迁移路线，禁止提问」。
本报告所有数字均可用文中命令复算；样本口径 = git ls-files（10 730 个被跟踪文件），不含 node_modules/、docs/19_资产/ vendored 资产。

§0 先报两条会改变结论的实测异常#

理论框架的 Phase 2 第 1 步要求「分析 git log --since="3 months ago" 的文件变更频率，标记热数据（>10 次/月）」。本仓该信号不可用，实测证据：

信号实测结论
git rev-list --count HEAD57 个 commit，首 commit 2026-07-25，单一作者 孔浩原历史被压扁/重建过，无 3 个月粒度可言
git log --since="3 months ago" --name-only每个文件计数恰好为 1等价于「全仓一次写入」，无频率分布
文件 mtime 分布（10 730 项）30 天内 8 667 / 90 天内 2 059 / 180 天以上 4批量重写痕迹，mtime 同样被污染

替代口径：本报告改用不被时间污染的结构信号 —— require 图的 fan-in（入度）做热/温/冷分级（§1.4、§2.1）。依据 5-3-1 §2「热温冷分离」的语义（访问频度与共享度），而非其字面实现（git 频率）。

第二条异常：git fsck 实测多条 hash-path mismatch（对象库损坏）。这直接击穿 5-3-1 §5「渐进式迁移」与 Phase 3「git mv 保留历史」的前置条件 —— 当前 .git 不可依赖，任何 git mv / git filter-repo 都必须排在 .git 重建之后（§3.0 第 0 步）。

2.1 五个顶级域（依据 §3「按生命周期/变更频率划分」）#

命名取业务术语（§3 明确要求，禁技术词），每域标注 §1.4 的热温冷档与实测来源：

域第 2 层唯一维度第 3 层唯一维度依据
